# Property Details v2.1.3 — Production Release

**Released:** 2026-10-09  
**Target:** Birchstone Hub / Interact HTML Page Composer, page ID `2186`  
**Companion repository:** `austinmhorn/birchstone-interact-customization`  
**Baseline rollback tags:** `stable-v2` (both repositories)

## Overview

One Composer-generated HTML document contains **Details View** and **Table View**, both backed by the existing property CSV and field-registry configuration. Details retains the existing property-level cards and quick links. Table offers an interactive portfolio-wide view using the same rendered records.

### Delivered features

- Switch between Details and Table without fetching a second data source.
- Search the full portfolio in Table View.
- Per-column chevron menu: ascending/descending sorting, searchable unique-value checklist, Select All, Clear, Apply.
- Multi-value OR within a column; AND across filtered columns. A highlighted chevron indicates an active filter.
- Registry-aware Columns chooser with persistent selections, Select All, and Reset to defaults. Property is pinned.
- CSV export uses filtered rows in visible sort order and selected visible columns; website links export full URLs.
- Website cells display clickable, normalized URLs (including `https://` where absent in source).
- Menus close on outside click or Escape. Display-only UI refinements restore native-looking checkbox dimensions in Interact.

## Source of truth and publishing

- Source: `Property-Details-Page-Composer/data/notion_data.csv` plus `data/property_fields.json`. Existing PDE and registry publishing controls remain in force.
- Renderer: `property_composer/renderer.py`; template: `templates/portfolio_details.html`.
- Generated preview: `output/portfolio_details.html`; publishable fragment: `output/portfolio_details.fragment.html`.
- Portal: **Pages → Property Details → Render → View Render** validates generated HTML, using presentation assets from the customization repository.
- **Publish** uses the saved fragment via `scripts/publish_portfolio.py --existing`. This updates Interact page `2186`, preserves existing page metadata, and does not send notifications. Avoid **Render & Publish** when deploying an already-reviewed render.
- Presentation CSS/JS lives in the companion customization repo; changes there may require deployment/republication depending on how production Interact loads assets. Confirm the live asset source rather than assuming a Git pull updates an already published page.
